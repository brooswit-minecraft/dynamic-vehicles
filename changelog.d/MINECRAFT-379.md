### Added
- Pathfinder region/circuit core (`pathfinder` package): deterministic 512x512-block region identity, Chebyshev ring enumeration, and a spatially-coherent circuit ordering, producing the designed 8/16/24/32-region circuits for levels 2-5 and an 8-checkpoint local loop for level 1 (settled 2026-10-18). A route is a pure function of origin region + level, so it is identical across villagers, retries, reload and multiplayer sessions.
- `PathfinderCheckpoint`/`PathfinderPosition`/`PathfinderCheckpointPlacer`: each checkpoint is a concrete, dimension-aware position with its own reach radius, not just "somewhere in this region" — a region can own several distinct checkpoints (level 1's local loop) or one (levels 2-5's ring regions). The actual terrain-safe placement strategy is still a placeholder (region-center/circle math, fixed height) pending acceptance criteria #4.
- `PathfinderProgress`: server-authoritative, in-order checkpoint validation (dimension + proximity, not region entry) with out-of-order rejection, an overall completion time limit evaluated atomically with every reach report, and a closing leg back to the first checkpoint.
- A new "Route Board" workstation block + POI type + `pathfinder` villager profession, registered the same way the Dispatcher's own dedicated block/POI avoid POI collisions (MINECRAFT-196), reusing the shared `VillagerJobSites` helper. Block/profession textures are an explicit placeholder (the Dispatcher's own board/profession art, reused) pending real art. No right-click interaction, route selection UI, HUD, or persistence yet — see MINECRAFT-379.

No player-facing gameplay yet: a Pathfinder villager can exist and claim a Route Board as its job site, but nothing lets a player start, progress through, or be rewarded for a circuit.
