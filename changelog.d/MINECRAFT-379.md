### Added
- Pathfinder region/circuit core (`pathfinder` package): deterministic 512x512-block region identity, Chebyshev ring enumeration, and a spatially-coherent circuit ordering, producing the designed 8/16/24/32-region circuits for levels 2-5 and an 8-checkpoint local loop for level 1 (settled 2026-10-18). A route is a pure function of origin region + level, so it is identical across villagers, retries, reload and multiplayer sessions.
- `PathfinderCheckpoint`/`PathfinderPosition`: each checkpoint is a concrete, dimension-aware position with its own finite, positive reach radius, not just "somewhere in this region".
- `PathfinderTerrainPlacer`: real, read-only terrain-safe checkpoint placement (reads the live heightmap at the same deterministic region-center/circle X/Z the core math picks; never modifies terrain), cached server-wide per (dimension, origin, level) by `PathfinderRouteStorage` so a route's checkpoint coordinates stay fixed across retries/reloads/later infrastructure edits even though the placer itself isn't a pure function.
- `PathfinderProgress`: server-authoritative, in-order checkpoint validation (dimension + proximity, not region entry) with out-of-order rejection, an overall completion time limit evaluated atomically with every reach report, and a closing leg back to the first checkpoint.
- A working vertical slice: right-click a Pathfinder villager (profession + "Route Board" workstation block/POI, reusing the shared `VillagerJobSites` helper) to start an attempt at its region/level; a coarse server tick evaluates each online player's active attempt, advances it on real movement, and grants an emerald reward (scaling with level) on completion while clearing the attempt before paying out (no duplicate rewards on reload). Persisted server-wide via `PathfinderAttemptStorage`/`PathfinderRouteStorage` (`SavedData`), survives reconnect/reload/restart. A minimal HUD overlay shows next-checkpoint direction and remaining time, mirroring the Dispatcher's own HUD pattern.
- Block/profession textures are an explicit placeholder (the Dispatcher's own board/profession art, reused) pending real art.

Not yet implemented: terrain-safe placement is read-only-heightmap only (no obstruction/safety beyond surface height); timer/reward values are plain constants pending a `ModConfigSpec`; death/disconnect semantics are "clock keeps running" with no special-casing. See MINECRAFT-379.
